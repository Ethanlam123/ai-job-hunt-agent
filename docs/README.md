## Quick Reference

- **Stack**: Next.js 16, TypeScript, Supabase, LangChain.js
- **Database**: PostgreSQL with pgvector extension
- **Auth**: Supabase Auth with Row Level Security (RLS)
- **Storage**: Supabase Storage for documents
